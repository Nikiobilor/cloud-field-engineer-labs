# Cloud Field Engineer: 2-Month Lab-Based Program
### Built for Nkiruka Judith Obilor | Target Role: Cloud Field Engineer 

## Program Philosophy

This program simulates life as a Cloud Field Engineer. Every session is a real ticket. I am responding to a production scenario, deploying infrastructure, solving the problem, handing it over, and documenting it. Exactly what Cloud Field engineers do daily.

**The stack:** Ubuntu Linux · Kubernetes (k3s/minikube) · OpenStack concepts · Terraform · Ansible · Python · AWS Free Tier · GitHub · Azure DevOps (free tier) · Joshi · Multipass
